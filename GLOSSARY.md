# Dependabot pull requests

Review and maintenance of dependency updates proposed by Dependabot.

## Language

**Recommendation**: An agent's assessment of what should happen to a Dependabot
pull request, based on its description, diff, checks, and available release
notes.

**PR action**: An approval, merge, or rebase request executed against a specific
Dependabot pull request within the scope authorized by the user.

**Upgrade issue**: An issue linked to a Dependabot pull request that records the
code changes and verification needed to adopt the update.

**Review report**: The agent's final account of the decisions, outcomes, and
remaining work for the Dependabot pull requests it reviewed.
